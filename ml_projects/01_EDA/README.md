# Task 01 — Exploratory Data Analysis (Iris Dataset)

- **Internship:** Happieloop Technologies (10 July – 9 August 2026)
- **Module:** `01_EDA` — Statistical Profiling & Multi-Variate EDA
- **Dataset:** Iris Flower Dataset (150 observations, 4 numerical features, 3 species: *Setosa*, *Versicolor*, *Virginica*)
- **API Endpoint:** `/api/task01/eda` and `/api/task01/scatter`

## Overview
Performs exploratory data analysis on the Iris dataset by computing descriptive statistics, quartiles, feature correlations, and class separability across species, while powering interactive EDA and scatter visualizations in the portfolio web interface.
